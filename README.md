# MTMS-HLDv1.0_Landslide_Segmentation
MTMS-HLD v1.0 is a standardized multi-temporal landslide dataset developed from Sentinel-2 imagery (2016–2025) over Pithoragarh, Uttarakhand. It contains 17,042 paired RGB image patches and annotation masks at four scales: 64×64, 128×128, 256×256, and 512×512 pixels.
